# 국제 사회는 어떻게 경쟁과 갈등, 협력을 할까?

## 근거

- 원자료: `[비상교육] 중등_사회 ②_6-2_교사용 교과서.pdf`
- 대상 쪽: PDF 내부 표기 109~110쪽(발췌 PDF 2~3쪽)
- 교과서 학습목표: 국제 사회에 존재하는 경쟁과 갈등, 협력의 다양한 모습을 이해한다.
- 성취기준(MCP 확인): `[9사(일사)11-01]` 국제 사회 행위 주체의 활동을 조사하고 국제 사회의 특징을 도출한다. / `[9사(일사)11-02]` 국제 사회의 분쟁을 조사하고 시민으로서의 역할을 토의한다.
- MCP 원문 출처: `kr-nec-2024-3-annex7`, PDF 71쪽, curriculum `kr-2022-middle-사회`, 조회일 2026-08-01
- 연계 후보(확정 아님): `[9사(지리)06-01] 자원 분포의 편재성과 자원 소비량의 지역적 차이를 파악하고, 이로 인해 발생하는 국가 간 경쟁과 갈등을 조사한다.` 카스피해 자원 갈등 활동과 직접 연결되지만, 교과서 판본·교육과정 적용 연도에 따라 MCP 확인 후 확정한다.

## 활동 설계 원칙

- 기본: 교과서의 개념·원인·사례와 국제 사회 행위 주체를 정리하고 빈칸으로 회상 확인
- 심화: 국제 사회의 분쟁을 하나 선택하여 주장-근거-반론-시민 역할 제안의 글쓰기 수행
- 사회과 공통 점검: 자료의 출처와 맥락을 확인하고, 사례에서 근거를 뽑아 주장과 연결
- 두 단계 모두 같은 핵심 목표와 맥락을 유지하며, 심화는 사고와 표현의 확장으로 구성

## 사용 순서

1. 109~110쪽을 읽고 학생용 기본 학습지 작성
2. 교사용 정답·해설로 즉시 피드백
3. 심화 글쓰기에서 사례를 하나 선택하고 10~15분 초안 작성
4. 출처·근거·반론 반영 여부를 확인하여 수정
