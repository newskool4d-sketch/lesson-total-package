# Subject Pedagogy Routing

패키지 레이어는 교과별 생성 규칙을 복제하지 않는다. 선택된 직접 모듈의 정본을 우선하고, 아래 비협상 원리만 공통 품질 게이트로 사용한다.

| 교과 | 공통 비협상 원리 | 대표 검증 질문 |
|---|---|---|
| 국어 | 학년 수준 텍스트 접근, 근거 기반 말하기·쓰기, 토론 전 개별 사고 기록 | 학생이 텍스트 근거를 사용하고 말하기 전에 생각을 기록했는가? |
| 수학 | 전략·표상 비교, 구조적 난도 유지, 설명과 정당화 | 정답 외에 전략 또는 표상의 이유를 설명하는가? |
| 과학 | 관찰·조사 후 설명, 증거 기반 모델 수정, 필요한 경우 정량 자료 사용 | 설명이 조사 증거와 모델 변화에 근거하는가? |
| 사회 | 출처 확인, 맥락화, 자료 간 교차검토, 근거 기반 주장 | 학생이 출처와 자료 간 관계를 확인한 뒤 주장을 세우는가? |

## Routing fields

`pedagogy_profile`에는 다음을 기록한다.

- `subject`: `context.subject`와 동일한 교과
- `non_negotiables[]`: 이번 수업에서 보존할 원리 1개 이상
- `selected_checks[]`: 산출물에서 실제로 확인할 증거 1개 이상

초등·고등학교 보통교과 밖·교과가 불명확한 요청은 이 표를 억지로 적용하지 않는다. 직접 모듈의 규칙이나 사용자 제공 자료를 우선하고, 근거가 없으면 `확인 필요`로 표시한다.
