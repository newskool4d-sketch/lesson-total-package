# Audience And Density Rules

패키지 산출물은 `teacher`, `student`, `shared` 대상을 명시한다.

## Audience rules

- `teacher`: 수업 단계, 관찰 포인트, 예상 난점, 자료 준비, 피드백 사용
- `student`: 학생이 읽고 수행할 과제, 근거, 응답 공간, 학생용 용어
- `shared`: 앵커·과제·출처처럼 대상별 산출물에 동일하게 들어가는 내용

`student`와 `shared`에는 학생이 볼 수 있는 자료를 넣는다. 교사용 지시·학생 관찰 메모·정답 및 해설·내부 평가 판단과 수준·능력군 표기는 교사에게만 보이는 자료와 분리한다. 학생이 직접 관찰 결과를 쓰는 기록표, 답을 설명하는 질문, 자기 점검 칸은 사용할 수 있다.

패키지와 수준별 자료 검증기는 두 대상에 동일한 표기 검사를 적용한다. 작성자는 제목 없이 본문에 들어간 모범 답안이나 교사 지시도 배부 전에 확인한다. 수준별 자료에서 공용 파일은 단계별 학생 활동지에 추가할 수 있다. 각 단계의 학생 활동지는 `student`로 등록한다.

## Density rules

- 긴 설명은 단계·표·목록으로 나눈다.
- 한 블록은 하나의 행동 또는 판단을 담는다.
- 과제의 요구 수준에 맞는 응답 공간을 제공한다.
- 수업 시간과 자료 목록은 실제 교실에서 실행 가능한 수준으로 제한한다.
- 같은 과제는 `task_id`를 통해 교사 계획·학생 자료·평가에서 동일하게 참조한다.
