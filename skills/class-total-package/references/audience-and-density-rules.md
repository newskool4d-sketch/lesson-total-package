# Audience And Density Rules

패키지 산출물은 `teacher`, `student`, `shared` 대상을 명시한다.

## Audience rules

- `teacher`: 수업 단계, 관찰 포인트, 예상 난점, 자료 준비, 피드백 사용
- `student`: 학생이 읽고 수행할 과제, 근거, 응답 공간, 학생용 용어
- `shared`: 앵커·과제·출처처럼 대상별 산출물에 동일하게 들어가는 내용

학생 자료에는 교사용 지시, 관찰 기록, 정답 및 해설, 내부 평가 판단을 넣지 않는다. 수준이나 능력군을 암시하는 표기도 넣지 않는다.

## Density rules

- 긴 설명은 단계·표·목록으로 나눈다.
- 한 블록은 하나의 행동 또는 판단을 담는다.
- 과제의 요구 수준에 맞는 응답 공간을 제공한다.
- 수업 시간과 자료 목록은 실제 교실에서 실행 가능한 수준으로 제한한다.
- 같은 과제는 `task_id`를 통해 교사 계획·학생 자료·평가에서 동일하게 참조한다.
