# 교사용 판서안

연못의 그늘진 곳과 햇빛이 드는 곳을 칠판의 두 칸에 나눠 수초 관찰 결과를 적는다.
두 칸에서 공통점과 차이점을 골라 표시하고, 관찰 결과로 설명할 수 있는 관계를 학생과 함께 정리한다.
