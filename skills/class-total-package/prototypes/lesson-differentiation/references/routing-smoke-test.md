# Differentiation Routing Smoke Test (Prototype)

## Must trigger

- 기존 과제를 지원 수준별로 조정해 줘.
- 같은 수업을 학습자 지원 프로필별로 나눠 줘.
- 아래·기본·확장 활동지를 같은 목표로 만들어 줘.

## Must not trigger

- 새 수업을 처음부터 설계해 줘.
- 수행평가 루브릭만 만들어 줘.
- PBL 단계만 설계해 줘.

## Failure signals

- tier별 목표·맥락·핵심 과제가 달라진다.
- 지원 프로필의 과제에서 핵심 인지 요구를 제거한다.
- 학생 자료에 수준·능력군 표현이 들어간다.
- 집단이 고정 능력군으로 표현되고 재편성 근거가 없다.
